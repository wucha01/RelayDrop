## 本次解决的构建问题

- 不再要求源码目录必须携带正式 APK。默认桌面构建不内嵌 APK，下载卡片按实际安装包可用性显示，下载接口测试改用合成字节。
- Electron 45 运行时采用显式安装入口，构建及桌面启动入口自动调用锁定版本的官方安装器。
- ASAR 资源核验适配 Windows 路径格式；EXE 属性使用通用项目名称，不沿用构建工具的公司名或本机个人署名。
- PowerShell 5.1 与 7 的子进程模块路径分别初始化，避免跨宿主继承造成标准命令缺失；APK 签名参数避免重复读取同一密码流。
- 服务端和网页版本号与 1.9.2 构建一致。
- Windows 无法读取正在被另一个进程操作的目录守卫时，返回“目录正在使用”，保持拒绝访问，不据此回收锁。
