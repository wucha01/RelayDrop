# 源码整理范围

本源码整理版以 1.9.2 为基础，保持业务功能和数据格式，修改构建入口、开发版身份、安装包可选下载和发布文档。没有导入旧 Git 历史。

| 位置 | 用途 |
| --- | --- |
| `server.cjs` 与根目录模块 | Node 文件池、校验、权限、备份、发现 |
| `public/` | 共享界面与浏览器端操作 |
| `desktop/` | Electron 原生窗口、托盘、保存与预览 |
| `android/` | Android Java 源码、资源与构建入口 |
| `remote/` | 可选远程连接协议与中继源码 |
| `vendor/` | 可离线使用的 PDF/X509 资源及许可证 |
| `scripts/` | 可移植构建与源码审计 |
| `test/` | 合成数据的 Node 自动化测试 |

未纳入个人文件池、设备状态、配对码、令牌、TLS 私钥、正式 APK/EXE、签名仓库、密码文件、测试截图、旧报告、依赖安装目录或本机缓存。代码中的测试密码、固定示例地址和第三方版权署名是用途明确的公开内容，不等同于用户秘密。

原个人插画未纳入此目录；桌面 SVG/PNG/ICO 与 Android 向量改用简单的双向箭头通用标识。派生图像不带 EXIF。文件只复制内容字节，不复制原文件的 NTFS 备用流、原始创建时间或来源标记。源码文件有文件系统自动产生的当前时间戳；Git 不跟踪 NTFS 所有者、创建时间、备用流或 Windows 代码签名属性。发布 ZIP 另行按固定时间戳生成，不携带这些本机属性。

开发版身份与正式版隔离，原软件数据和正式签名留在原位置。随源码保留的公共证书 `android/res/raw/webview_trust_anchor.pem` 是证书而非私钥；它不是本机运行时生成的 TLS 身份。NanoHTTPD JAR 是固定版本的第三方依赖，保留许可与哈希；不是个人编译产物。

源码目录无安装包是正常情况。服务仍可运行，安装包下载卡片根据实际可用文件显示；下载路由测试使用临时合成字节，完整 APK 另由 Android 构建验证。构建报告只使用相对路径，不写入签名密码。
